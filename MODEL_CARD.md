# Карточка модели: классификатор новостных тем

## Назначение

Модель относит новостной материал к одной из **11 тематических категорий**:
политика, экономика, технологии, наука, здоровье, спорт, культура, происшествия,
автомобили, недвижимость, другое.

Применение — **локальная сортировка новостной ленты на устройстве пользователя**.
Модель не предназначена для принятия решений о людях, модерации контента,
фильтрации по политическим или идеологическим признакам.

## Вход и выход

| Параметр | Значение |
|---|---|
| Вход | заголовок и описание новости, до 96 токенов |
| Выход | распределение вероятностей по 11 классам |
| Токенизатор | WordPiece (BERT), нормализация по `BertNormalizer` |
| Формат поставки | ONNX, INT8-квантование |

## Данные

- Размеченный набор: **5 757** обучающих, **903** валидационных,
  **903** тестовых примера.
- Псевдоразмеченный пул: **+2 194** примера, отобранных по уверенности модели,
  разнице между топ-классами и энтропии распределения, с балансировкой классов.
- Данные **синтетические** — сформированы на основе реальных новостных заголовков.
  Это означает, что распределение тем и формулировок отражает конкретный набор
  источников, а не новостное поле в целом.
- Язык: русский.

## Обучение

Дообучение `DeepPavlov/rubert-base-cased`. Три прогона с разными начальными
состояниями, отбор лучшей модели по macro-F1 на валидации. Против дисбаланса
классов — веса классов и label smoothing. Часть описаний при обучении случайно
отбрасывалась, чтобы модель работала на источниках без описаний.

## Метрики

Замер на отложенной выборке (903 примера, не участвовали в обучении):

| Метрика | Значение |
|---|---|
| Accuracy | 85,2 % |
| Macro-F1 | 0,778 |
| Согласие INT8 с FP32 | 99 % |

**Почему macro-F1 ниже accuracy.** Macro-F1 считается как среднее по классам,
поэтому редкие темы влияют на него так же сильно, как частые. Разрыв между 85,2 %
и 0,778 означает, что по редким категориям модель ошибается заметно чаще, чем
по массовым. Для сортировки ленты это допустимо; для задач, где важна каждая
категория, — нет.

## Ограничения

- **Точность 85,2 %** — примерно каждая седьмая новость попадает не в свою тему.
  Модель не подходит для сценариев, где ошибка классификации имеет последствия.
- **Разметка по одной теме.** Материал на стыке тем (например, «экономика
  и технологии») относится к одной категории; модель не выражает неопределённость
  между ними.
- **Синтетические данные.** На источниках с другой стилистикой, длиной заголовков
  или тематикой качество может быть ниже заявленного.
- **Усечение до 96 токенов.** Длинные описания обрезаются; если тема выражена
  в конце текста, она может быть потеряна.
- **Только русский язык.** На других языках модель неприменима.
- **Дисбаланс классов сохраняется.** Редкие категории классифицируются хуже —
  это видно по разнице accuracy и macro-F1.
- **Разбивка по классам не опубликована.** Полная матрица ошибок в открытом
  доступе не приводится.

## Этические соображения

- Модель **не является средством массовой информации** и не формирует
  новостную повестку: она только раскладывает по темам уже полученные заголовки.
- Классификация выполняется **на устройстве**, тексты новостей не передаются
  на серверы и не используются для обучения сторонних моделей.
- Приложение не собирает персональные данные и не использует рекламные
  или аналитические SDK.
- Ошибка классификации влияет только на то, в каком разделе пользователь увидит
  новость; оригинальный текст и ссылка на первоисточник сохраняются всегда.
